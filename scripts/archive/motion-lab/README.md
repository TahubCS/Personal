# Archived motion-lab experiments

These scripts produced historical step-2 drawing comparisons and recordings. They have been superseded by the maintained commands in [the scripts guide](../../README.md).

Run historical scripts from the repository root, not this directory. Their existing artifact paths are intentionally preserved. They may need captures or other inputs from their original iteration; they are not release verification and should not be used as evidence of the current prototype without a fresh run and inspection.
